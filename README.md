# Yaka Kamerası Haritası

Türkiye'de polis yaka kamerası uygulamasının 2014–2026 yayılımını gösteren tek sayfalık site (harita, rakamlar, kronoloji, kaynaklar).

Tüm site `index.html` dosyasındadır; derleme adımı yoktur. GitHub Pages ile yayımlamak için: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ardından dalı ve `/ (root)` klasörünü seçin.
